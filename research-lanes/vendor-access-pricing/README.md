# Vendor Access And Pricing

Use this folder to track which tools are worth buying or trialing for RALPH.

## Buy Decision Rule

A paid tool should have:

- a target RALPH question
- exact metric/data needed
- expected sample size
- cheaper public alternative already tried or ruled out
- explicit spend cap
- approval before signup/payment/API key
- storage path for exports that excludes secrets

## Pricing Freshness

Pricing changes. Every row should include:

- `observed_at`
- source URL
- price or "quote/contact sales"
- access requirement
- RALPH fit
- buy status

## Status Values

- `active-free`
- `trial-candidate`
- `cheap-candidate`
- `expensive-benchmark`
- `contact-sales`
- `avoid-for-now`
