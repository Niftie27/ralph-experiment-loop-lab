# Framework Rails

Trading bot frameworks are later-stage validation or paper-trading rails. They are not selected during M0.

Framework research can start before framework selection. The goal is to learn system patterns, not to pick a live trading stack.

Order:

1. Intelligence and evidence
2. Validation and benchmark
3. Framework choice
4. Paper trading
5. Execution, only with explicit future approval

## Candidates

- Freqtrade: strategy validation and paper-trading candidate.
- Hummingbot: market-making/execution framework candidate.
- Homerun: needs purpose and suitability verification.
- Custom harness: likely best for replay, benchmark, and research-specific tests.
