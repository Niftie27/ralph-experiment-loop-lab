# Decision Framework

RALPH decisions use five states:

- `investigate`: evidence suggests this is worth deeper research.
- `benchmark`: claim needs reproducible validation.
- `prototype`: evidence and validation justify a small prototype.
- `watch`: interesting but not ready.
- `discard`: not worth current attention.

Every candidate needs:

- thesis
- unknowns
- evidence required
- data rails
- validation method
- cost/risk
- next action

Every decision needs:

- date
- decision
- rationale
- evidence
- caveats
- revisit trigger

Candidate promotion uses `core/candidate-scoring.md`.
