# Investigation Loop

Purpose: turn a candidate into a structured research brief.

Inputs:

- candidate
- related unknowns
- source summaries
- data rail notes
- case file context

Actions:

1. State the thesis.
2. Gather evidence.
3. Identify what would falsify it.
4. Identify data needed for validation.
5. Estimate cost, complexity, and risk.
6. Recommend next state: benchmark, watch, discard, or prototype-later.

Outputs:

- `outputs/investigation-briefs/<slug>.md`
- updated candidate
- updated unknowns
- possible experiment plan
