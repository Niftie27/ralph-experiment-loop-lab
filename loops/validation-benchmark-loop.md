# Validation/Benchmark Loop

Purpose: test claims before prototypes.

Inputs:

- investigation brief
- benchmark plan
- local datasets
- public/free data rails
- Zela methodology lessons

Actions:

1. Define claim to validate.
2. Define metric.
3. Define dataset and collection method.
4. Define caveats before measuring.
5. Run local read-only analysis when possible.
6. Record results and caveats.
7. Recommend decision state.

Outputs:

- experiment result
- benchmark memo
- decision memo draft

Safety:

- No live execution.
- No wallet keys.
- No exchange accounts.
