# Market/Battlefield Loop

Purpose: collect high-signal context about events, volatility, security incidents, protocol changes, and ecosystem movement.

Inputs:

- `crypto-updates/` local source map and scoring rules
- public protocol blogs and status pages
- security incident reports
- price/volatility context where relevant
- DefiLlama and similar public data rails

Actions:

1. Scan approved public/free sources.
2. Extract only items relevant to RALPH candidates or unknowns.
3. Create battlefield notes under `wiki/notes/` or case files.
4. Promote repeated patterns to candidates.
5. Flag incident/event candidates for the wallet-shadow case file.

Outputs:

- battlefield note
- updated unknowns
- updated candidates
- possible investigation brief

Safety:

- No trading.
- No alert-to-execution path.
- Market movement is context, not instruction.
