# X / GitHub Research Loop

Purpose: find strategy, architecture, and failure-mode knowledge from public GitHub repos, docs, and public X/Twitter-like discussion sources.

## Scope

This loop does not look for hype calls or trade signals. It looks for reusable system knowledge:

- trading bot strategy families
- event-driven bot designs
- backtest and simulation patterns
- wallet/entity intelligence workflows
- MEV/searcher architecture and failure modes
- liquidation monitoring examples
- repo maturity and maintenance signals
- real operator warnings

Seed keywords:

- trading bot framework
- crypto trading bot backtesting
- event driven trading bot
- volatility trading bot crypto
- wallet shadowing
- copy trading wallet delay
- smart money wallet tracking
- MEV searcher simulation
- liquidation bot monitor
- EVM replay simulation
- Freqtrade strategy
- Jesse strategy
- NautilusTrader backtest
- Hummingbot strategy
- vectorbt crypto
- revm anvil arbitrage

## Actions

1. Search local RALPH memory first.
2. Search public GitHub and docs.
3. Search public web/X mirrors or browser-searchable discussions when useful.
4. Record exact source links.
5. Score sources for maturity, reproducibility, and relevance.
6. Promote only items that change a candidate, unknown, or testing plan.

## Outputs

- source candidate
- source summary
- repo/framework note
- unknown/candidate update
- discard note for low-signal hype

## Safety

- No keys.
- No account auth.
- No live trading.
- No paid APIs.
- Do not scrape private or login-only content.
