# RALPH Loops

RALPH loops are bounded recurring research processes.

The core loop chain:

1. Source Intake Loop
2. Unknowns Loop
3. Market/Battlefield Loop
4. Discovery Loop
5. Investigation Loop
6. Validation/Benchmark Loop
7. Decision Loop
8. Portfolio Output Loop
9. Self-Improvement Loop
10. Strategy Research Loop
11. Framework And Repo Discovery Loop
12. X / GitHub Research Loop
13. Market Volatility Watch Loop

Loops can run manually in `A1` mode. Scheduled automation requires approval and a runbook in `automation/`.
