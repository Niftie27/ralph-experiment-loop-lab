# Discovery Loop

Purpose: find candidate sources, rails, signals, entities, or opportunities worth investigating.

Inputs:

- open unknowns
- candidate list
- battlefield notes
- data rail map
- case files

Actions:

1. Pick one unknown or candidate.
2. Search local memory first.
3. Search public sources if needed.
4. Record source candidates.
5. Decide whether to ingest, investigate, watch, or discard.

Outputs:

- source candidates
- candidate updates
- investigation briefs
- discard records

Stop condition:

- The loop produces a concrete next action, or records why it cannot.
