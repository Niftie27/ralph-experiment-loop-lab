# Portfolio Output Loop

Purpose: keep Tomas oriented without flooding him.

Inputs:

- decisions
- candidates
- open unknowns
- active experiments
- recent battlefield notes

Outputs:

- short status brief
- next best investigations
- stale items to discard
- blockers needing Tomas

Default format:

1. What changed
2. Top candidates
3. Top unknowns
4. Recommended next action
5. What was discarded or deprioritized
