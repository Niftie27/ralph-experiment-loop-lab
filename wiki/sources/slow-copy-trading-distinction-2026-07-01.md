# Slow Copy-Trading Distinction

## Summary

Tomas clarified that his continuing interest in copy-trading means following slow mid-cap spot accumulators that hold for weeks, not mirroring fast perp traders.

This is a key distinction:

- fast perp mirroring violates Tomas's no-latency constraint;
- slow accumulator following fits the patient-retail strategy map if it survives forward testing.

## RALPH Implication

RALPH should stop treating copy-trading as one bucket.

The correct split is:

- fast copy-trading = reject, radar-only, or prior-art reference;
- slow accumulator following = valid smart-money branch.

## Main Caveat

The slow branch is not easy. It moves the main problem from entry latency to exit/distribution, selection bias, and mid-cap liquidity/data coverage.
