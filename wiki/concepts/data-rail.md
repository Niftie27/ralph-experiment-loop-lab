# Data Rail

A data rail is a source or access path that can improve RALPH research: Arkham, Nansen, Dune, DefiLlama, raw on-chain data, protocol docs, alerts, benchmark outputs, and curated feeds.

Each rail must be evaluated for coverage, exportability, cost, reliability, and time saved.
